Sobre CSS

O CSS é utilizadopara definir a aparência dos elementos de uma página HTML.

Podemos alterar as cores, os tamanhos, as fontes e os espaçamentos.

Formatação de texto

Podemos deixar uma palavra em negrito.

Também podemos utilizar itálico em um texto.
